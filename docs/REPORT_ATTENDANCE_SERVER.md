# Отчёт посещений с устройства на сервере

Эндпоинт `GET /report/attendance-from-device` запрашивает данные **напрямую у устройства Hikvision** (камера/NVR) по HTTP. Поэтому при развёртывании на сервере важно следующее.

## Ошибка «Ошибка подключения: timed out»

Она означает: **сервер не смог за отведённое время подключиться к устройству** (по IP из `HIKVISION_DEVICE_IP`).

### Что проверить

1. **Доступность устройства с сервера**  
   Устройство должно быть доступно по сети **с той машины, где запущен backend**:
   - если backend на сервере в интернете (например, testdomen.uz), а камера в офисе за роутером — запрос с сервера до камеры не дойдёт (нет маршрута);
   - нужна либо общая сеть (backend и камера в одной LAN), либо VPN/туннель с сервера до сети, где стоит камера.

2. **Настройки в `.env` на сервере**
   - `HIKVISION_DEVICE_IP` — IP, с которого **сервер** пингует/достучивается до камеры (не localhost, если backend не на той же машине).
   - `HIKVISION_DEVICE_PORT` (обычно 80).
   - `HIKVISION_DEVICE_USER`, `HIKVISION_DEVICE_PASSWORD` — учётные данные ISAPI.

3. **Таймаут**  
   По умолчанию запрос к устройству ждёт 60 секунд. Если сеть медленная, в `.env` на сервере можно увеличить:
   ```env
   HIKVISION_REQUEST_TIMEOUT=90
   ```
   (значение в секундах).

### Варианты при недоступности камеры с сервера

- Поднять **прокси/агент в сети с камерой**, который ходит к Hikvision и отдаёт данные вашему backend по API.
- Либо держать backend (или отдельный сервис отчёта) **в той же сети, где камера**, и отдавать отчёт во внешний фронт через ваш основной домен/прокси.
